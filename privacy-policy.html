서비스: 목표 시각화 (브랜드: 그로우온 / 패키지: com.joychristy.growon)

‘목표 시각화’(이하 “서비스”)는 이용자가 입력한 목표와 소망을 바탕으로 AI가 이야기를 만들어 주는 앱입니다. 이용자가 적는 내용은 매우 사적일 수 있어, 우리가 무엇을 받고 어디에 두며 누구에게 보내는지를 아래에 빠짐없이 적었습니다.

1. 수집하는 개인정보 항목

항목수집 시점필수/선택
익명 계정 식별자(UUID)앱 최초 실행 시 자동 생성(회원가입 없이 이용 가능)필수
이메일 주소이용자가 정식 가입을 선택한 경우에만선택

생성된 이야기·확언AI 생성 결과필수

읽기 기록·기분 체크인세션 완료 시선택

수집하지 않는 정보: 위치, 연락처, 사진·파일, 통화·문자 기록, 광고 식별자, 기기 식별자. 서비스에는 광고 SDK와 분석·크래시 수집 SDK가 포함되어 있지 않습니다. 앱이 요청하는 권한은 인터넷 접속, 알림 표시, 생성 중 백그라운드 작업 유지뿐입니다.

알림 시각, 낭독·배경음악 on/off, 읽기 속도, 글씨 크기, 테마 등 앱 설정값은 서버로 전송되지 않고 이용자 기기에만 저장됩니다.

2. 이용 목적

  • 이야기·확언 생성 및 제공(서비스의 핵심 기능)
  • 낭독 오디오 생성 및 재생
  • 읽기 기록·연속 기록(streak) 표시
  • 구독 상태 확인 및 결제 검증
  • 생성 횟수 관리(요금제별 한도 적용 및 비용 남용 방지)
  • 유입 경로 통계 및 문의 응대

3. 보관 장소와 국외 이전

수집된 정보는 Supabase(데이터베이스·인증·파일 저장소)에 보관되며, 서비스가 사용하는 리전은 아시아·태평양(서울, ap-northeast-1)입니다. 아래 4·5항의 처리 위탁 과정에서 일부 데이터가 국외(미국 등)의 서버로 전송됩니다.

4. 제3자 처리 위탁 (AI·음성 생성)

서비스는 이야기와 낭독을 만들기 위해 아래 사업자에게 처리를 위탁합니다. 모든 호출은 서비스 서버에서만 이루어지며, 앱에는 어떤 API 키도 포함되어 있지 않습니다.

수탁자전송되는 정보목적
Anthropic, PBC이용자가 입력한 온보딩 답변 텍스트이야기·확언 생성
OpenAI, L.L.C.생성된 이야기 문장 텍스트낭독 음성 합성(무료 이용자)
ElevenLabs, Inc.생성된 이야기 문장 텍스트낭독 음성 합성(프리미엄 이용자)
Supabase, Inc.1항의 저장 항목 전체데이터베이스·인증·파일 저장
Google LLC구매 토큰, 앱 패키지명구독 결제 및 결제 검증

이용자가 입력한 답변은 AI 이야기 생성을 위해 Anthropic에 전송됩니다. 위 사업자들은 우리를 대신해 데이터를 처리하는 수탁자이며, 우리는 이용자 정보를 광고·마케팅 목적으로 제3자에게 판매하거나 제공하지 않습니다.

5. AI 생성 콘텐츠에 대한 고지

서비스가 보여주는 이야기와 확언은 AI가 생성한 콘텐츠이며, 앱 화면에도 그렇게 표시됩니다. AI 생성물은 사실이 아닐 수 있고, 의학적·법률적·재무적 조언이 아닙니다. 부적절한 생성물은 읽기 화면의 신고 기능으로 알려 주시면 해당 콘텐츠를 차단합니다.

6. 보유 기간

  • 계정과 이용자가 만든 콘텐츠: 회원 탈퇴 시까지 보관하며, 탈퇴와 동시에 삭제합니다.
  • 생성 이력: 요금제 한도 관리 목적상 계정이 존재하는 동안 보관합니다(내용 없이 생성 시각·영역명만).
  • 결제 관련 기록: 관계 법령에서 정한 기간(전자상거래법상 대금결제 기록 5년 등) 동안 보관할 수 있습니다.

7. 계정 및 데이터 삭제 요청

앱에서 직접 삭제하기

설정 → 계정 → 회원 탈퇴를 누르면 계정과 함께 답변, 생성된 이야기, 낭독 오디오, 읽기 기록, 구독 정보, 추천 코드가 모두 삭제되며 되돌릴 수 없습니다.

콘텐츠만 지우고 계정은 남기고 싶다면 설정 → 처음부터 다시 설정을 이용하세요. 답변·이야기·읽기 기록이 삭제됩니다(무료 이용자의 생성 횟수 기록은 유지됩니다).

앱 없이 삭제 요청하기

앱을 이미 삭제하셨거나 앱에서 삭제할 수 없는 경우, breezeholicmall@gmail.com 으로 “계정 삭제 요청”이라는 제목과 함께 가입에 사용한 이메일 주소(또는 앱 설정 화면에서 확인한 계정 식별자)를 보내주세요. 본인 확인 후 영업일 기준 7일 이내에 계정과 관련 데이터를 모두 삭제하고 회신드립니다. 결제 기록 등 법령상 보존 의무가 있는 항목은 해당 기간 동안만 분리 보관한 뒤 파기합니다.

8. 이용자의 권리

이용자는 언제든지 자신의 정보에 대한 열람·정정·삭제·처리정지를 요청할 수 있습니다. 앱 설정 → 데이터 내보내기·가져오기에서 자신이 만든 이야기를 JSON 파일로 내려받을 수 있으며, 그 밖의 요청은 위 문의 이메일로 접수해 주세요.

9. 안전성 확보 조치

  • 앱과 서버, 서버와 수탁자 사이의 모든 통신은 HTTPS/TLS로 암호화됩니다.
  • 저장된 데이터는 저장소 제공자(Supabase)의 저장 시 암호화(AES-256) 정책에 따라 보호됩니다.
  • 이용자별 접근 제어(Row Level Security)를 적용해 다른 이용자의 데이터에 접근할 수 없습니다.
  • 낭독 오디오 파일은 비공개 저장소에 보관하며, 재생할 때마다 짧은 수명의 서명된 링크를 새로 발급합니다.
  • AI·음성 합성 API 키는 서버에만 보관하며 앱에 포함하지 않습니다.

10. 만 14세 미만 아동

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다. 아동의 정보가 수집된 사실을 알게 되면 지체 없이 삭제합니다.

11. 방침의 변경

이 방침이 변경되면 변경 사항과 시행일을 이 페이지에 게시합니다. 중요한 변경은 앱 내 공지로도 알립니다.
