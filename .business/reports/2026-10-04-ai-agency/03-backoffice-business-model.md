## 0. 한 줄 요약

> **"셀러 사장이 매일 아침 엑셀을 열지 않아도, 어제 채널별 진짜 순이익과 오늘 처리할 이상 징후가 카톡으로 오게 만드는 운영 대행."**
> 셋업비는 낮게(99만~199만원), 월 운영비(29만~89만원)를 본 매출로 잡는다. 운영 계약 없이 셋업만 하는 상품은 팔지 않는다. 크몽에서는 서버가 필요 없는 "파일 업로드형" 단건만 판다.

### 이번 추가 검색에서 설계를 바꾼 사실 4가지

| 사실 | 설계에 미친 영향 |
|---|---|
| **장사왕**(셀러 손익 SaaS)이 월 5.5만원(2계정)·11만원(20계정)·33만원에 쿠팡·스마트스토어 순이익 자동 계산과 **매일 아침 전날 매출·순이익 알림**을 판다 | "일일 손익 리포트"만으로는 월 49만원을 받을 수 없다. 리테이너의 가치는 **툴이 못 하는 것**, 즉 원가·SKU 매핑 관리 대행, 자사몰·도매·3PL 같은 비표준 데이터, 정산 대사, 공급사 발주, 이상 징후를 사람이 해석해 주는 것에 둔다. 라이트 요금제를 29만원으로 낮췄다 |
| 통합관리 솔루션 가격: 사방넷 월 20만~45만원(가입비 30만~70만원), 플레이오토 월 12.8만~29.9만원, 이지어드민 월 30만~60만원(가입비 20만원) | 셀러는 이미 백오피스 도구에 **월 20만~60만원**을 쓰고 있다. 우리 리테이너 29만~89만원은 이 범위 안에 있다. "사방넷을 대체"가 아니라 **"사방넷 옆에서 사방넷이 안 하는 일"**로 포지셔닝한다 |
| **쿠팡 Open API 키는 판매자ID당 1개만 발급**되고, 유효기간이 **180일**이다. 이미 다른 솔루션이 키를 쓰고 있으면 새로 발급할 수 없고, 같은 키에 IP를 추가해 같이 쓰는 방식으로 연동한다 | ① 온보딩 때 "기존 연동업체 유무"를 반드시 확인한다. 기존 키를 공유받는 절차를 SOP에 넣는다 ② 180일 만료 전 재발급 대응은 리테이너 업무로 명시한다(운영 계약이 필요한 실질 근거) |
| 네이버 커머스API와 쿠팡 API는 모두 **호출 서버 IP를 등록**해야 한다 | 고객의 구글 시트(Apps Script)처럼 IP가 바뀌는 환경에서는 API 자동 수집이 안 된다. **고정 IP 서버 = 창업자 인프라**가 기술적으로 필요하다. 그래서 "API 자동 수집형은 운영 계약 필수"라는 구조가 자연스럽다. 반대로 크몽 단건은 API를 쓰지 않는 "정산 파일 업로드형"으로 만든다 |

## 2. 가격 정책과 상품 사다리

### 2-1. 가격 근거

| 비교 대상 | 가격 | 우리와의 차이 |
|---|---|---|
| 장사왕(손익 SaaS) | 월 5.5만 / 11만 / 33만원(VAT 포함) | 셀프서비스. 원가 입력·매핑은 셀러가 직접. 비표준 채널·정산 대사·발주는 범위 밖(추정) |
| 사방넷 | 월 20만~45만원 + 가입비 30만~70만원 | 주문·재고 통합이 중심. 손익 해석·맞춤 알림은 약함(추정) |
| 플레이오토 / 이지어드민 | 월 12.8만~29.9만원 / 30만~60만원 | 위와 같음 |
| 크몽 셀러 자동화 단건 | 수만~수십만원(발주 자동화, 정산 마진 템플릿, API 연동) | 한 번 납품하고 끝. API 변경·키 만료·원가 변동 대응 없음 |
| 크몽 업무 자동화 평균 | 30만~100만원(파이썬·API), ERP 연동 200만원 이상 | 범용 구축 |
| 사무직 1명 | 월 200만원 이상 | 엑셀 반복 업무 일부를 대체 |

**가격 원칙**
1. 셋업비는 크몽 단건 기준점(수십만원)과 너무 벌어지지 않게 **99만원부터** 시작한다. 스크리닝에서 지적한 "150만~300만원은 높게 들린다"를 반영했다.
2. 운영비는 "통합관리 솔루션 1개 값(월 20만~45만원)"과 "사무직 인건비의 1/4" 사이에 둔다.
3. **API 자동 수집형 셋업은 운영 계약(최소 3개월)과 묶어서만 판다.** 기술적으로도 고정 IP 서버가 필요하므로 설명이 자연스럽다.
4. 첫 3곳은 셋업비 50% 할인(파일럿 가격), 운영비는 정가. 할인 대가로 수치 사례(익명) 사용 동의를 받는다.

**크몽 규정 준수 원칙**
- 크몽은 결제 전 개인 연락처(SNS·휴대폰 번호) 공유를 금지하고, 직접 결제를 유도하거나 실행하면 7일 → 30일 → 90일 이용 제한을 건다. 2026-02-05 판매 이용약관 개정으로 서비스 상세 정보에 직접 결제를 유도하는 문구를 쓰는 것도 금지됐다.
- 그래서 **크몽 고객은 처음부터 끝까지 크몽 안에서만 거래한다.** 상품 설명, 메시지, 납품물(시트 안 문구 포함)에 자체 사이트·연락처·"직거래 시 할인" 같은 문구를 넣지 않는다.
- 크몽 단건은 API 자동 수집이 아니라 파일 업로드형이므로 서버 운영이 필요 없다. 크몽 고객이 API 자동화를 원하면 크몽에 **별도 셋업 상품과 월 운영 상품을 올려서 크몽 결제로** 받는다(수수료를 감수한다).
- 크몽의 가치는 **리뷰·레퍼런스와 고객 언어 수집**이다. 리테이너 매출의 본진은 자체 채널이다.
- [확인 필요] 크몽에서 같은 고객이 매달 재구매하는 형태가 정책상 문제없는지, 크몽 고객센터 판매 가이드 원문으로 확인한다(원문이 네트워크 정책으로 열리지 않아 검색 요약만 확인함).

| **M-REPORT** | 리포트 렌더러 | 일일 브리핑, 주간, 월간 손익계산서. 출력 대상: 슬랙, 텔레그램, 이메일, 카카오 알림톡(심사 통과 템플릿), 구글 시트 | 1~2주차 |
| **M-PO** | 발주서 생성기 | 공급사별 엑셀 양식 템플릿 → 매일 정해진 시간에 생성·메일 발송 | 4주차 (프로 첫 고객 시) |
| **M-NARR** | LLM 해설 | 숫자는 코드로 계산하고, LLM은 "주간 변화 3줄 요약"과 "이상 징후 설명"만 쓴다. 숫자 검증 후 발송 | 2주차 |
| **OPS** | 운영 모니터 | 잡 성공·실패, 데이터 지연, **쿠팡 키 만료 D-14·D-3 알림**, 일일 발송 확인, 백업 | 1~2주차 |
| **TENANT** | 고객 설정 파일 | `tenants/<고객>.yaml`: 채널, 키 참조, 요금제, 알림 규칙, 수신처. 신규 고객 = 이 파일 1개 + 매핑 | 1주차 |

**인프라와 보안 기본값**
- 고정 IP VPS 1대(월 3만~5만원)에서 모든 고객을 테넌트로 분리해 운영한다. 고객 30곳 정도까지는 1대로 충분하다(추정).
- API 키는 암호화 저장(sops/age 또는 클라우드 KMS), 코드 저장소에 넣지 않는다. **읽기 권한만** 쓴다.
- 구매자 개인정보(이름·주소·전화)는 손익 계산에 필요하지 않으므로 **수집 단계에서 버리거나 해시 처리**한다. 발주서 자동화(프로)에서만 수령인 정보를 임시로 쓰고 발송 후 삭제한다.
- 일일 백업, 월 1회 복구 테스트.

## 7. 계약서 핵심 조항

표준 템플릿 1개를 만들고, 첫 계약 전에 변호사 1회 검토를 받는다(예산 30만원 이내 배정, 추정). [확인 필요] 아래는 설계 의도이며 법률 문구가 아니다.

| 조항 | 핵심 내용 |
|---|---|
| **1. 범위** | 부속서 A에 채널, 자동화 목록, 리포트 항목, SKU 상한, 요금제를 표로 적는다. **부속서에 없는 것은 범위 밖.** 쓰기 API(상품·가격·주문 상태 변경)는 별도 합의 없이는 하지 않는다 |
| **2. 변경 요청(CR)** | ① 요금제에 포함된 "소규모 개선"은 4시간 이내 작업에 한정 ② 그 이상은 서면(메시지 가능) 견적 → 고객 승인 후 착수, 시간당 8만원 또는 고정가 ③ 채널 추가, SKU 상한 초과는 요금제 변경 ④ 승인 안 된 작업은 하지 않으며 청구도 하지 않는다 |
| **3. 대금** | 셋업: 선금 50% / 검수 후 잔금 50%. 검수는 D4 대조 기준(±0.5%) 충족 시 완료로 보고, 통보 후 5영업일 안에 이의가 없으면 검수 완료로 간주. 운영비: 매월 1일 선불, 세금계산서 발행. 14일 이상 미납 시 리포트 발송 일시 중지 |
| **4. 기간·해지** | 운영 최소 3개월, 이후 월 단위 자동 연장. 해지는 30일 전 서면 통지. 최소 기간 내 고객 사정으로 해지하면 잔여 기간 운영비의 50% 청구. 공급자 귀책(장애 복구 목표를 한 달에 3회 이상 못 지킴)이면 위약금 없이 즉시 해지 가능 |
| **5. 해지 후 처리** | ① 고객 데이터(정규화된 주문·정산·손익 이력)를 CSV로 14일 안에 전달 ② 이후 30일 안에 우리 서버의 고객 데이터와 키를 삭제하고 **삭제 확인서** 발급 ③ 고객은 해지일에 API 키를 폐기·재발급해야 함(안내 제공) ④ 자동화 코드·모듈은 공급자 소유이며 고객에게는 계약 기간 동안 이용권만 있다. 코드 이관을 원하면 별도 이관비(셋업비와 같은 금액)로 협의 |
| **6. 데이터·API 키 관리 책임** | ① 키는 **고객 명의**로 발급하고 소유권도 고객에게 있다 ② 공급자는 최소 권한(읽기)만 쓰고, 암호화 저장하며, 계약 목적 외에 쓰지 않는다 ③ 키 유출이 의심되면 24시간 안에 고객에게 통지하고 재발급을 요청한다 ④ 고객 쪽 사정(비밀번호 공유, 직원 퇴사, 다른 업체 키 관리)으로 생긴 사고는 고객 책임 ⑤ 셀러센터 로그인 계정은 받지 않는다 |
| **7. 개인정보 처리위탁** | 공급자는 수탁자. 처리 목적(정산·손익 집계, 발주서 생성), 항목 최소화(구매자 정보는 저장하지 않음이 원칙), 재위탁(클라우드 서버) 고지, 보관 기간, 파기, 안전성 확보 조치, 사고 시 통지. 고객은 자기 개인정보처리방침에 수탁자를 공개한다 |
| **8. 결과물의 성격·책임 한도** | 리포트·알림은 **경영 참고 자료**이며 세무 신고, 정산 이의 제기, 발주 결정의 최종 책임은 고객에게 있다. 공급자의 손해배상 한도는 직전 3개월 받은 운영비 합계. 간접 손해(매출 손실 등)는 제외. 단, 공급자의 고의·중과실은 예외 |
| **9. 플랫폼 정책 변경** | 네이버·쿠팡 등의 API 변경·중단·키 정책 변경은 불가항력. 공급자는 통지받은 날부터 3영업일 안에 대체 방법(엑셀 업로드 등)을 제안하고, 복구될 때까지 리포트를 대체 방식으로 유지한다. 대체가 불가능해 범위가 줄면 운영비를 일할 감액 |
| **10. 서비스 수준** | 평일 10~18시 응대. 장애 복구 목표는 요금제별(라이트 2영업일 / 스탠다드 1영업일 / 프로 4시간). 정시 발송률 월 99% 미만이면 다음 달 10% 감액 |
| **11. 레퍼런스** | 고객 동의 시 상호·브랜드를 가린 수치 사례 공개. 파일럿 할인 고객은 동의를 조건으로 한다 |
| **12. 비밀유지** | 상호 2년 |

## 11. 월 500만원 도달 시나리오와 1인 상한

### 11-1. 기본 시나리오 (부가세 별도, 크몽은 수수료 차감 전 금액)

가정(추정): 운영 평균 단가 42만원(라이트 30% / 스탠다드 55% / 프로 15%), 셋업 평균 140만원(파일럿 할인 반영 후 정가로 상승), 월 이탈 5%.

| 월 | 신규 셋업 | 셋업 매출 | 운영 고객(월말) | 운영 매출 | 크몽 | **합계** |
|---|---|---|---|---|---|---|
| 10월 (M1) | 2 (파일럿 50%) | 100만 | 2 | 30만 (일할) | 50만 | **180만** |
| 11월 (M2) | 2 | 200만 | 4 | 130만 | 40만 | **370만** |
| 12월 (M3) | 2 | 280만 | 6 | 220만 | 30만 | **530만** ← 첫 도달(셋업 의존) |
| 1월 (M4) | 2 | 280만 | 8 | 310만 | 20만 | **610만** |
| 2월 (M5) | 1.5 | 210만 | 10 | 390만 | 20만 | **620만** |
| 3월 (M6) | 1 | 160만 | 12 | **480만** | 20만 | **660만** ← 운영비만으로 500만원 근접 |

**보수 시나리오**: 셋업 월 1건, 운영 평균 35만원, 월 이탈 10% → 운영 고객 9곳(315만원) + 셋업 140만원 = **월 455만원(M6)**. 500만원은 M7~M8. 이 경우 W8 재설계에서 스탠다드 비중을 올리거나 가격을 조정한다.

**핵심 메시지**: 3개월 차 500만원은 **셋업 매출이 받쳐 줘야** 가능하다. "운영비만으로 500만원"은 운영 12곳(평균 42만원) 이후, 즉 6개월 차다. 셋업 매출은 매달 영업이 필요하므로, M4부터는 영업 시간을 소개·SEO로 자동화해야 한다.

### 11-2. 원가

| 항목 | 월 비용 (추정) |
|---|---|
| VPS(고정 IP) + 백업 | 3만~5만원 |
| LLM API | 1만~3만원 |
| 알림톡 발송 (12곳 × 일 3건 × 30일 ≈ 1,100건) | 1만~2만원 |
| 크몽 수수료 (월 20만원 매출 기준 16.4%) | 약 3만원 |
| 합계 | **10만원 안팎 → 매출 600만원 기준 마진 약 98%** (창업자 인건비 제외) |

**초기 예산 100만원 배분**: VPS 3개월 15만원, 도메인 2만원, 계약서 변호사 검토 30만원, 알림톡 충전 5만원, 크몽 진단·데모용 소액 10만원, 예비비 38만원.

### 11-3. 1인 상한

| 항목 | 계산 |
|---|---|
| 납품 가능 시간 | 주 20시간 × 4.3주 = **월 86시간** (영업·관리 주 10시간 별도, `02-ideas.md` 공통 가정) |
| 운영 고객 1곳당 | 월 4~6시간 (월간 리뷰 0.5~1시간 + 관리 대행 1~2시간 + 장애·문의 1~2시간 + 리포트 검토 1시간) |
| 셋업 1건 | 스타터 8시간 / 스탠다드 15시간 (모듈 재사용 후) |
| **상한** | 운영 **14~16곳**(약 70~80시간) + 셋업 월 1건 → 운영 15곳 × 45만원 + 셋업 140만원 = **월 약 800만원** |
| 상한을 정하는 진짜 요인 | 시간보다 **동시 장애**(플랫폼 API 변경이 모든 고객에 한꺼번에 영향)와 **월초 리뷰 몰림**. 대응: 월간 리뷰를 첫째~셋째 주로 분산, 플랫폼 변경은 커넥터 1곳만 고치면 되도록 모듈화 |

**상한 이후 선택지 (6개월 이후 판단)**
1. 신규 고객 가격 인상(스탠다드 49만 → 59만원)
2. 운영 보조 파트타이머 1명(원가표 갱신·매핑·리포트 검토, 시급 1.2만원 × 월 40시간 ≈ 48만원) → 상한 25곳
3. 운영 데이터가 쌓이면 라이트 요금제를 셀프서비스로 전환(사실상 SaaS화). 단, 창업자는 "앱 단독 판매형"을 피하고 싶다고 했으므로 대행이 본업이고 셀프서비스는 저가 입구로만 둔다

## 12. 주요 위험과 대응

| 위험 | 신호 | 대응 |
|---|---|---|
| 셋업만 사고 운영비를 거절 | 진단 콜에서 "한 번 만들어 주면 제가 돌릴게요" | API 자동 수집형은 고정 IP 서버가 필요하다는 기술적 이유로 운영 계약을 필수로 설명. 끝까지 거절하면 크몽형 파일 업로드 상품으로 안내(자체 채널에서도 판매 가능) |
| 장사왕 같은 SaaS와 가격 비교 | "장사왕은 11만원인데요" | "툴은 사장님이 원가·매핑을 직접 넣고 확인해야 합니다. 저희는 그걸 대신하고, 자사몰·도매·정산 입금 대사·발주까지 합니다." 비교표를 랜딩에 둔다. 단일 채널·소규모 셀러는 장사왕을 권하고 받지 않는다 |
| 쿠팡 키 공유 문제 | 기존 연동업체가 키를 쥐고 있어 IP 추가가 안 됨 | 온보딩 D1에 확인. 불가하면 쿠팡은 엑셀 업로드 커넥터(C-XLS)로 대체하고 요금 조정 |
| 플랫폼 API 변경·정책 변경 | 커넥터 오류 급증 | OPS 알림, 계약서 9조, 엑셀 대체 경로 상시 유지 |
| 숫자 오류로 신뢰 상실 | 셀러센터 숫자와 불일치 | D4 대조 검수(±0.5%), 수수료 규칙표 버전 관리, LLM은 숫자 계산에 쓰지 않음 |
| 개인정보 사고 | — | 구매자 정보 미저장 원칙, 암호화, 처리위탁 계약, 접근 로그 |
| 크몽 제재 | 크몽 고객이 외부 연락 요청 | 응하지 않는다. 크몽 안의 상품으로만 안내 |
